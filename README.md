# Календариус

Прогрессивное веб-приложение (PWA) для удобного планирования задач и управления расписанием.

## О проекте
Календариус – это инструмент для тех, кто хочет навести порядок в своих делах. Приложение позволяет создавать задачи, распределять их по категориям (Работа, Учёба, Личное) и управлять расписанием с помощью интуитивного интерфейса с поддержкой Drag & Drop.

## Ключевые возможности
* **Система категорий:** Визуальное разделение задач по цветам
* **Drag & Drop:** Перетаскивание задач между временными слотами
* **Офлайн-доступ:** Использование технологии PWA для работы без постоянного подключения к интернету
* **Кроссплатформенность:** Работает в любом современном браузере

## Функционал
1. Планирование задач

Как пользователь, я хочу создавать задачи с указанием времени, описания и цвета категории, чтобы визуально структурировать свой день и отделять учебу от личных дел.

Как пользователь, я хочу видеть задачи в разных режимах (день, неделя, месяц), чтобы контролировать как текущие дела, так и долгосрочные планы.

2. Гибкость управления

Как пользователь, я хочу перетаскивать задачи (Drag & Drop) в календаре, чтобы быстро изменять расписание при возникновении непредвиденных обстоятельств.

Как пользователь, я хочу переносить задачи из блока «Незавершеные задачи» в конкретный день, чтобы планировать дела из записной книжки в активное расписание.

3. Индивидуальная настройка

Как пользователь, я хочу создавать свои списки задач (категории), чтобы организовать планирование под свой личный ритм жизни (например, "Хобби", "Тренировки").

Как пользователь, я хочу удалять задачи двойным кликом, чтобы быстро очищать календарь от выполненных или ненужных дел.

4. Доступность и надежность

Как пользователь, я хочу работать с приложением в офлайн-режиме (PWA), чтобы иметь доступ к расписанию даже в условиях отсутствия интернета.

Как пользователь, я хочу сохранять прогресс локально без обязательной регистрации, чтобы сразу приступить к работе без лишних шагов.

## Технологический стек
* **Backend:** Python, Flask
* **Frontend:** HTML5, CSS3, JavaScript
* **Система сборки:** Setuptools
* **Контейнеризация:** Docker

## Запуск проекта

### Локально
1. Убедитесь, что у вас установлен Python 3.x.
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите приложение:

```Bash
python app.py
```
4. Откройте http://localhost:5000 в браузере.

### Через Docker
1. Соберите образ:
``` Bash
docker build -t calendarius .
```

2. Запустите контейнер:
``` Bash
docker run -p 5000:5000 calendarius
```
